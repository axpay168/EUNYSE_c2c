# eurforex_c2c Database

This folder is reserved for the `eurforex_c2c` database assets so they are not mixed with any `new_c2c` deployment files.

- Runtime database name: `eurforex_c2c`
- Runtime database user: `eurforex_c2c`
- Schema snapshot: `mysql_schema.php`

Keep environment-specific secrets in `backend-api/.env`; do not commit real credentials.
